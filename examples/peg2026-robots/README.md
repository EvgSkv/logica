# Logical Robots — PEG 2026 Examples

Complete solutions for the levels discussed in the paper
*"Embodied Declarative Logic: How Logical Robots Provide an Intuitive Pathway to Learning Logica"*
(PEW 2026).

## How to run

1. Go to [logica.dev/robots](https://logica.dev/robots)
2. Copy the contents of a `.l` file into the editor
3. Select the corresponding level and press Play

## Levels

| File | Level | Description |
|------|-------|-------------|
| `level3-freedom.l` | Level 3 | A single robot avoids walls using WeightedAverage |
| `level6-beacon.l` | Level 6 | Following a trail of beacons to "Sweet Home" |
| `level8-formation.l` | Level 8 | Robots stay in formation behind a leader |
| `level10-labyrinth.l` | Level 10 | Distributed Bellman-Ford shortest paths |
| `level12-charger.l` | Level 12 | A charger robot shuttles fuel to a cargo robot |
